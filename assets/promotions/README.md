# Brasões de promoções

24 PNGs originais servidos localmente, sem redesenho. Fonte: [Slayer Legend Wiki — Promotions](https://slayerlegend.wiki/character/promotions), que referencia [BenDol/SlayerLegendCDN](https://github.com/BenDol/SlayerLegendCDN/tree/main/game-assets/images/promotions). Consultado em 19/10/2026.

Arquivos mantêm os nomes do repositório de origem. A correspondência entre arquivo, ID e nome de exibição está em `js/promotions.js`; Warfrost usa `14-winterfrost.png` e Eldenwood usa `23-elderwood.png`, conforme a tabela da wiki. Os gráficos do jogo pertencem aos respectivos titulares; este portal é comunitário e não oficial.
